# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and help keep this a welcoming project
for everyone regardless of background or experience. Harassment, insults and personal attacks are
not tolerated in issues, pull requests or any other project space.

To report unacceptable behavior, contact the maintainer privately through a
[GitHub security advisory](https://github.com/croos555/bucketeer/security/advisories/new) (it stays
private) or by the contact listed on the maintainer's GitHub profile. Reports are handled
confidentially.
